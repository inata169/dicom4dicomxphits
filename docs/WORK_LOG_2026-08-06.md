## Audit implementation

The audit was strengthened without modifying the DICOM data:

- Audits human-readable VRs in the main Dataset, every nested Sequence, and File
  Meta Information.
- Uses tag-specific approved values or cryptographic fingerprints for reviewed
  text, dates/times, instance identifiers, and other context-sensitive values.
- Rejects non-empty AE Titles, unregistered public elements, private elements,
  overlays, nested Pixel Data, unexpected bulk data, duplicate tags, invalid
  string syntax, and values that appear in the wrong tag or VR context.
- Checks protected patient attributes beyond names and identifiers, including
  demographic and physical-measurement fields.
- Continues parsing elements after root-level Pixel Data so trailing elements are
  also audited. Root-level Pixel Data itself is not decoded by the text audit.
- Preserves the existing checksum, modality, and DICOM-reference integrity checks.
- Runs the trusted-base audit before proposed audit code in GitHub Actions, then
  runs the proposed audit and unit tests.
